# Changelog

Public behavior changes are recorded here. The project uses
[Semantic Versioning](https://semver.org/) with an explicitly evolving pre-1.0 API.

## 0.1.0 - 2026-11-02

First public educational release.

- Typed, dependency-free calculations for simple and logarithmic returns,
  compounded growth, total return, annualized volatility, and drawdowns.
- Strict dated CSV input and a command-line JSON report, with explicit numerical
  and estimation conventions.
- Reproducible synthetic data and worked notebook examples.
- Independent numerical tests, property tests, strict type checking, and package
  installation checks.
- Locked development dependencies, pinned CI actions, security-reporting guidance,
  and documented limitations.

This is authored educational software. It does not establish learner validation,
observed investment performance, production adoption, or an external certification.
